# MK-V baseline audit — 2026-10-12

The checked-out integrated baseline is `feat/immersive-story` at `5ba23f3`, remote `origin` = `https://github.com/TrishulVani/trishul-vani-studio.git`. MK-IV is present at `web/hardware.html`, with the user-provided assembly converted to 261 WebGL mesh entries in `web/assets/hardware-scene-v2.json`. No GLB, source CAD, mechanical dimensions or licensed speech bundle is in this checkout. The current V2 landing is `web/index.html?design=2`; V1 remains at the root. The live V2 alias still serves an earlier public candidate and is not a signoff for this branch.

The current design uses near-black/forest surfaces, restrained copper and gold borders, ivory text, Manrope body and Syne display type. `web/brand-v2.css` applies the gold `त्रि` wordmark and glyph. The shared browser favicon is the green `web/favicon.svg`. The workbench controls use dark instrument cards and visible focus rings. MK-V should reuse these tokens and marks, without a broad rebrand.

The existing 3D JSON is illustrative and has selectable headset, microphone, ADC, processor, enclosure, link and receiver objects. It lacks dimensioned source geometry, texture maps, PBR environment, named mechanical connector specifications and importable GLB. MK-IV offers chapter orbit/zoom/open/explode/cutaway; mouse pan, touch pinch, part-specific engineering BOM, hardware telemetry and measured communications are not implemented. Existing FastAPI `/api/experiments/simulate`, `/api/experiments/{id}`, and audio routes provide genuine offline DSP output from synthetic input. `/api/meta` reports whether real RNNoise is available; this audit does not assume it is.

Baseline screenshots of V2 and MK-IV at 1440×900, 1024×768 and 390×844 are in [screenshots](screenshots/). They were captured from the local integrated branch, not the older public release. The MK-V generated product photograph is concept artwork and will be labeled as such; it is not evidence of a manufactured device.

Current validation: `python -m pytest -q --basetemp .pytest-hardware-mkv` passed 17 tests; the first run without `--basetemp` failed only because the sandbox temp directory could not be created. `node node_modules/@playwright/test/cli.js test --workers=1` passed 63 desktop/tablet/mobile checks after correcting assertions for the changed brand. MK-V checks remain required before any release.
