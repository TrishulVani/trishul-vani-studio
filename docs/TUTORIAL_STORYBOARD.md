# Guided tour and future video shot list

There is no completed product-video asset. The live first-visit experience is a five-step, skippable tour tied to existing controls. This is the authentic capture plan for a later 80-second tutorial; every screen must be recorded from a functioning build and must use actual results.

| Time | Screen / action | Narration and caption |
|---|---|---|
| 00–08 | Public trident entrance, then real Mission Control | A research workbench for comparing speech-enhancement methods. |
| 08–22 | Audio Laboratory; select a real control for Factory, Wind or Impulse; adjust SNR | Choose a controlled environment and set the input SNR. |
| 22–34 | Run Signal Analysis, await completed API run | One input is processed through multiple tested paths. |
| 34–50 | Play RAW, NLMS, spectral and hybrid outputs, user-triggered | Listen to every output; filtering alone is not quality. |
| 50–62 | Measured SNR, metrics table and N/A fields | A score needs the right reference. Unavailable values stay unavailable. |
| 62–74 | Spectral Studio; import permitted WAV, select time/frequency region and preview | Inspect the real spectrogram and make a non-destructive edit. |
| 74–80 | Download WAV and JSON recipe | Export the evidence and reproduce the work. |

Captions draft: [`tutorial-captions.vtt`](tutorial-captions.vtt). Record only permitted material. Do not show synthetic tones as intelligible speech, fake benchmark numbers, or an RNNoise pass when no model ran. A recorded video will require user approval of the resulting cut before publication.
